==nTPL: simple, fast and powerful templates for node.js (https://github.com/truedat101/nTPL).
A revived fork of the original nTPL by Fedor Indutny, modernized to build and run
on current Node.js (20 / 22). Comes with optional <b>Express.js</b> integration.

==Status (v0.5.0):
This fork was modernized for Node 20/22. See CHANGELOG below and DESIGN.md for the
architecture and the rationale behind the changes.

==Some features:
* Native parser written in C++ via N-API (node-addon-api) - ABI-stable across Node releases.
* Templates are compiled once to a JS function and cached, so rendering is fast.
* Extendable via nTPL.modificators (the "block", "filter" and "set" plugins ship in the box).
* Can reload a template when its file changes (watch: true).

==Security note:
nTPL compiles templates by eval()-ing generated JavaScript. This is fine for
trusted template files, but you must NOT compile attacker-controlled template
strings - expressions inside {%= ... %} run as arbitrary JavaScript. Treat
template sources like code, not user input.

==Installation:
	npm install nTPL

The native parser is built automatically on install via node-gyp.

==Requirements:
* Node.js 20 or 22 (uses N-API).
* A C/C++ toolchain for the native addon (build-essential / Xcode CLT / MSVC) and python3 -
  the standard node-gyp prerequisites.

==Advanced / from source:
	git clone https://github.com/truedat101/nTPL.git
	cd nTPL
	npm install        # installs deps and builds the native addon
	npm test           # runs the test suite

To rebuild the addon after editing src/ntpl_native.cc:
	npm run build      # alias for: node-gyp rebuild

==Basic examples:
	var ntpl = require("nTPL").plugins("nTPL.block", "nTPL.filter").ntpl;
	
	ntpl("1 + 1 = {%= 1+1 %}")();
	ntpl({
		template : "1 + 1 = {%= 1+1 %}"
	})();
	ntpl("filename.tpl")();
	// 1 + 1 = 2
	
	ntpl({
		template : "Hello {%= a %}!",
		args: ["a"]
	})({a: 'World'});
	// >> Hello World!
	
	ntpl({
		template: "Hello {%each a%}{%= this %}, {%/each%}world!",
		args: ["a"]
	})({a: ['Andy','Alex']});
	// >>  Hello Andy, Alex, World!
	
	ntpl({
		template: "{%if godmode%}My Lord!{%else%}Who are you?{%/if%}",
		args: ["godmode"]
	})({godmode: true});
	// >> My Lord!
	
	var $ = require("ntpl");
	$.parse("It also works!")();
	// >> It also works!
	
==Medium examples:
	
	ntpl("foo {* text here won't be compiled or printed *} bar")();
	// >> foo  bar
	
	ntpl("{%each [1,2,3] %} "{%= this %}" {%/each%}?")();
	// >> "1" "2" "3" 
	
	ntpl("{%catch var a %}What's up, dude?{%/catch%}{%= a.substr(0,9) %}?")();
	// >> What's up?
	
	ntpl({
		template: "filename.tpl",
		callback: function (tpl) {
			console.log(tpl());
		}
	});
	// Will load "filename.tpl" in async mode
	
==Harder examples:
		
	ntpl({
		template: "<button>{%= value%}</button>",
		args: ["value"],
		name: "input"
	});
	ntpl("input")({value:'Hello world!'});
	// >> Button with text "Hello world!"
	
	ntpl({
		template: "filename.tpl",
		callback: function (tpl) {
			console.log(tpl());
		},
		watch: true
	});
	// Will load "filename.tpl" in async mode
	// And watch for file changes (template will be refreshed)
	// P.S. Also available in a sync mode
		
==Block module

	var ntpl = require("ntpl").plugins("ntpl.block").ntpl;
	
	ntpl({
		template: "Hello, {%block 'username'%}{%/block%}!{%= message %}",
		args: ["message"],
		name: "block-test"
	});
	ntpl("{%extends 'block-test', {message: "How do you do?"}%}{%block 'username'%}Admin{%/block%}")();
	// >> Hello, Admin!How do you do?

==Set modificators
	
Use "set" modificator to setup options inside template

===Examples:
"set.html"
	{%set name first template %}
	{%set args a1, a2, a3 %}
	{%set some 123 %}
	{%set foo.bar 1,2,3 %}
	{%= a1 %}
	{%= a2 %}
	{%= a3 %}

Template generated from this file will have 'first template' name and can get 'a1', 'a2', 'a3' as arguments

	var tpl = ntpl("set.html");
	ntpl("first template")({a1:1,a2:2,a3:3});
	tpl.options; // {name: "first template", args: ["a1", "a2", "a3"], some: "123", foo : { bar: ["1","2","3"] } }

===More info:
You can't setup any other options now. Only 'name' and 'args' are allowed.
But if you generated template with "watch=true" and then change {%set ... %} in template - 'name' and 'args' will be refreshed!

==Exports

	var lib = require("nTPL");
	lib.ntpl    // the template function (also lib.parse and lib.nTPL - all the same)
	lib.plugins("nTPL.block", "nTPL.filter") // install plugins, returns lib for chaining
	lib.render("name@file")                  // Express.js style render
	lib.modificators                         // the modificator table (extend it to add tags)

The conventional entry point is:

	var ntpl = require("nTPL").plugins("nTPL.block", "nTPL.filter").ntpl;

==Changelog

===0.5.0 - Modernization for Node 20/22
* Native parser rewritten with N-API / node-addon-api (was unbuildable legacy V8 code).
* Replaced removed Node APIs (path.exists / path.existsSync) with fs equivalents.
* The "set" modificator is now implemented in JS and works out of the box.
* require("nTPL").ntpl now resolves (was a .nTPL vs .ntpl casing bug); .parse and .nTPL
  are kept as aliases.
* Removed the global process.on('uncaughtException') handler that silently swallowed errors.
* Build is now `npm install` (node-gyp); the native binary is located at runtime via `bindings`.
* Dropped obsolete build scripts (wscript, install.sh) and the old ~2010 native sources.
* All 37 tests pass on Node 22 (`npm test`).
